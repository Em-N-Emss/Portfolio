# Comment ajouter un ISO dans un Proxmox serveur

L'idée est que l'on ne peut rien faire si les ISO ne sont pas accessibles dans le serveur

Pour cela il faut les upload et ces derniers se trouveront dans un compartiment de disque spécial appelé `local`

## Upload un ISO

Cliquer sur `Datacenter` -> `pve` -> `local(pve)` -> `Upload`
