# Linux dans Windows

Depuis 2019, Microsoft une nouvelle technologie permet d'installer et de configurer un environnement Windows avec Linux, sans avoir à [[DualBoot]]

Cette technologie est appelé **==*WSL soit Windows Subsystem for Linux*==**.

Je profite ainsi des avantages de Linux et son terminal dans Windows

J'ai installé et personnalisé le mien selon ma config qui peut être trouvé ici https://github.com/Em-N-Emss/.dotfiles

J'ai suivi ce tuto pour le setup pour tourner **==*Ubuntu*==** et **==*Kali-Linux*==** : https://www.youtube.com/watch?v=27Wn921q_BQ
